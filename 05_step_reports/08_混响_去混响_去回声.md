## 4. 关键数字

### 4.1 混响 → 分离退化（正面结果）

T60（**导出口径 44.1 kHz**）：小房间 **0.491 s** ／ 大厅 **1.026 s**。

| 模型          | 小房间 ΔSDR | 大厅 ΔSDR | 短回声 ΔSDR | 长回声 ΔSDR |
| ----------- | -------: | ------: | -------: | -------: |
| bsrnn_all   |   −5.844 | −14.544 |   −4.589 |   −6.037 |
| convtasnet  |   −3.476 | −10.683 |   −2.598 |   −3.570 |
| demucs      |   −5.648 | −15.648 |   −4.215 |   −5.868 |
| mdx         |   −5.940 | −15.231 |   −4.324 |   −5.966 |
| mmdenselstm |   −3.967 | −13.537 |   −2.716 |   −3.944 |
| umx         |   −3.350 | −11.450 |   −2.318 |   −3.329 |

- 均值曲线 `mean_curve`（干 / 小 / 大）：混响 **[0.0, −4.704, −13.516]**；回声 **[0.0, −3.46, −4.786]**
- **回声/混响 破坏力 = 0.35×**（= 4.786 / 13.516 = 0.3541），即混响比回声致命约 **2.8 倍**

### 4.2 去混响（负结果，照报）

| 项                         | 值                     |
| ------------------------- | --------------------- |
| Dereverb-Echo `dry` 支增益中位 | **0.044**（最大 1.464）   |
| wet 支损失区间                 | **[−13.3, −10.4] dB** |
| 判定                        | unusable（dry 支近乎静音）   |
| **官方分块推理路径交叉验证 Δ**        | **0.142 dB**          |

> 结论：两个社区 ckpt 在本探针**不可用**；已用官方推理路径交叉验证 → **非我方实现错误**。

## 5. 结论与坑

- ✅ **正面结果**：混响随 T60 **严格单调**地破坏分离（干 0 → 小 −4.70 → 大 −13.52）。
- 🟠 **负结果照报**：去混响模型在本探针不可用，且已用官方路径证明非实现问题。
- 🔴 **坑 1（dpi 顺序依赖）**：`figs_time/fig1..7*.png` 曾被 `cost.figures`（默认 dpi）与 `paper.figures`（300 dpi）**写同一路径** → 字节取决于执行顺序。**修法**：重建目标统一注入 `MATPLOTLIBRC`（`savefig.dpi:300`）→ 管线幂等。
- 🔴 **坑 2（导出率口径）**：RIR 卷混后必须**导出为 44.1 kHz 再评测**，否则 T60/ΔSDR 口径不一致（源 48k 只作脚注）。
- ✅ **坑 3（不污染主表）**：混响结果写独立 JSON，主表不受影响。
