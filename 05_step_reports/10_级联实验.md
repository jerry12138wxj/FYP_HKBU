**链路设计**：

| 链路 | 含义 |

## 4. 关键数字

### 4.1 跨格中位（n=16，单位 dB，Δ = 该链路 − L0）

| 量 | 中位 |
|---|---:|
| ΔSDR `L1`（降噪前置） | **−3.993** |
| ΔSDR `L1b`（仅带宽，恒等对照） | −0.894 |
| **★净降噪动作 `L1−L1b`** | **−3.214（占 80%）** |
| ΔSDR `L1m`（mel 前置） | −0.239 |
| ΔSDR `L2`（后置） | −0.060 |
| ΔSDR `L3`（前后置） | −4.012 |

> **核心结论：伤害主因是「降噪动作本身」，不是带宽代价；后置近中性、救不回前置损失。**

### 4.2 方向规律（反证对照臂有效）

- **净降噪动作随输入 SNR 单调恶化**：−5 dB → −0.635；+10 dB → **−6.087**（输入越干净跌得越狠）。
- **带宽代价与 SNR 基本无关**（−1.74 ~ +0.077）。
- 两者走势不同 → **反证 `L1−L1b` 抽出的确实是网络行为**，不是管线固定损耗。

### 4.3 机理：分离器退化为恒等映射

前置后各轨输出电平（相对输入 rms 中位）：

| 变体 | vocals | drums | bass | other | 含义 |
|---|---:|---:|---:|---:|---|
| V0 | 0.381 | 0.490 | 0.371 | 0.404 | 参照臂 |
| V1bl | 0.421 | 0.446 | 0.430 | 0.343 | ≈ V0 → 只付带宽代价 |
| V1mel | 0.429 | 0.457 | 0.431 | 0.321 | ≈ V0 → mel 近恒等 |
| **V1den** | **0.989** | **0.038** | **0.014** | **0.048** | ★vocals≈1 而 drums/bass/other→0 → **分离器退化为恒等映射** |

→ denoiser 把 **drums/bass/other 当噪声压掉** → 属**任务错配**，非实现错误。

### 4.4 门禁与锚点

| 项 | 值 |
|---|---|
| 数据门禁 | **90/90 PASS** |
| 锚点（干档直送） | **40/40 PASS** |
| 分离格 | **640/640 PASS** |
| 恒等式 `L1 = L1b + (L1−L1b)` 逐格残差 | **0.000000** |

## 5. 结论与坑

- ✅ **负结果照报**：前置降噪使分离 ΔSDR 中位 **−3.99 dB**，48 个前置格中 **40 为负**。
- 🔴 **坑 1（门禁语义）**：旧判据 `0.01 ≤ level ≤ 10` 把 35 格（V1den）**真实现象**判 FAIL → 被 summary 的 status 过滤吃掉 → 整列 None。
  **修法**：正确判据 = 输入没写坏 **且** 输出非全零、无异常数值 → 重判 **680/680 PASS**。
- ⚠️ **稀释效应**：后置只改 vocals → `avg4` Δ 被**稀释 4 倍**。
- ⚠️ **中位数不可加**：`L1 = L1b + (L1−L1b)` 逐格恒等，但中位数之间 0.12 dB 差**不是交互项**。
- 🔴 **数据纪律**：数字核验脚本 `_t6_verify.py` **只读 CSV、绝不手填**。
