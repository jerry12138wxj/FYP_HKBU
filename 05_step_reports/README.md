## 阅读约定

- 每篇汇报固定结构：**这一步要什么 → 做了什么 → 产出什么 → 关键数字 → 结论与坑 → 到哪看细节**。
- 汇报是**导航层**，不复制细节：所有细节仍以 `04_reports/*/docs/` 的原始文档为准（每篇末尾给链接）。
- **本目录只新增、不覆盖历史**：每步一篇独立文件，历史上的任何文档都未被改动。
- 日期一律写绝对日期。未确认的信息标「待确认」，不臆造。

## 与其它模块的关系

```
05_step_reports/   ← 你在这里（过程留档：怎么一步步做出来的）
04_reports/        ← 交付物本体（图表 / 看板 / 论文材料 / 各阶段详解文档）
01_models/         ← 模型代码与权重（本地开源源码）
02_databases/      ← 数据集
03_outputs/        ← 逐模型推理产物
tools/             ← 全部脚本（含一键复现工具）
```
