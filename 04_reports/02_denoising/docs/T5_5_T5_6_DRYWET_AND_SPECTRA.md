## 1. T5.5 · dry/wet 强度曲线

### 1.1 旋钮定义

`facebookresearch/denoiser` 官方提供 `--dry` 参数（`denoiser/enhance.py`）：

```
estimate = (1 - dry) * model(noisy) + dry * noisy        # dry ∈ [0, 1]
```

- `dry = 0` → 纯模型输出 = **主表当前配置**
- `dry = 1` → 完全直通 = 不降噪

这给出一条**连续的降噪强度轴**。mel-roformer 无此旋钮，故本实验只覆盖 3 个 denoiser 权重。

### 1.2 实现要点（三处必须遵守，否则数字不可信）

1. **契约率链（P19 铁律）**：输入先重采样到 `run_fn.contract_sr = 44100` 再喂，
   wrapper 内部降到 16 kHz 推理。**绝不能把已降采样的 16 kHz 当 44.1 kHz 喂。**
2. **混合必须在等价带宽通路上做**。denoiser 输出经 44.1k→16k→44.1k 往返，
   带宽已被限到 8 kHz。若直接与**原始** 44.1 kHz 输入混合，dry 项会带回
   模型本应抑制的 8~22.05 kHz 能量，混合结果失真。
   本实验把输入也过一遍 16k 往返再混合，两条支路带宽一致。
3. **整段混合，不做逐帧流式**。`DemucsStreamer(dry=...)` 是实时场景的逐帧混合，
   帧边界会引入不连续。本实验用 `enhance.py` 非流式分支的语义（整段线性混合）。

### 1.3 ✅ 正确性锚点（本实验可信的前提）

`dry = 0` 必须与主表**逐条逐位**一致。已校验：

```
compared = 12 (抽检)   worst_abs_diff = 0.0000   → PASS
```

校验脚本 `tools/_scratch/_drywet_anchor_check.py`。若不一致，说明 dry/wet 路径与主表
路径存在实现分歧，整张图作废。

### 1.5 三条结论

**结论 1 · 降噪强度是一个真实可调的旋钮，且最优值随输入 SNR 单调移动。**
`<5dB` 档最优在 `dry=0`（该降就降，不要往回混）；`>=15dB` 档最优右移到
`dry=0.2`（dns48）/ `0.1`（dns64）。**单一固定强度不可能同时最优** ——
这是「按输入 SNR 分层」纪律的又一独立证据（呼应 P11/P14）。
注意 `dry=1`（完全直通）落在 ΔSI-SDR = −0.01、ΔPESQ = +0.013，
即**基线自身的零点**，这与定义一致（直通 = 不做任何事），可作为本实验的第二个内部一致性检查。

**结论 2 · ★ PESQ 最优强度按权重**分化**，且分化方向与 P16 一致。**

| 权重 | ΔPESQ 最优 dry | dry=0.0 | dry=0.1 | 稀释的后果 |
|---|---:|---:|---:|---|
| dns48 | **0.1** | +0.551 | **+0.739** | 稀释后**改善 +34%** |
| dns64 | **0.1** | +0.601 | **+0.727** | 稀释后**改善 +21%** |
| master64 | **0.0** | **+0.963** | +0.867 | 稀释后**恶化 −10%** |

> 🔴 **这是对 P16 反转的一次完全独立的验证。** P16 的结论是「master64 是本项目的
> in-domain 权重（其训练集含 Valentini），因此它在主表上反转为最优」。
> 本实验从一个**完全不同的角度**（强度旋钮）得到同一结论：
> master64 在 `dry=0`（纯模型输出）处即达峰值，任何稀释都让它变差；
> 而两个 out-of-domain 权重需要**往回混 10% 原信号**才达到各自的 PESQ 峰值。
> 一条规律在两种独立实验下同时成立，可信度远高于单次观测。

**结论 3 · ΔSI-SDR 与 ΔPESQ 的最优工作点不一致，且这个分歧在 P19 修复后依然存活。**

| 指标（dns48, ALL） | 最优 dry | 该点数值 | dry=0 数值 | 差异 |
|---|---:|---:|---:|---:|
| ΔSI-SDR | 0.0 | +9.86 | +9.86 | — |
| ΔPESQ | **0.1** | **+0.739** | +0.551 | **+34%** |

> 🟠 与 P11 时期的分歧**性质不同**：这次不是符号相反（所有 dry 上两者都为正），
> 而是**最优工作点不同**。
> 归因：SI-SDR 是波形保真度（对残留噪声敏感），PESQ 是感知质量（对语音失真敏感）。
> dry=0.1 多保留的那 10% 原信号，把 SI-SDR 拉低一点（+9.86→+9.74），
> 却把 PESQ 抬高一截（+0.551→+0.739）——说明纯模型输出引入了**感知上更疼的语音失真**。
>
> 🔴 **对工程实践的直接影响**：选型时若只报 SI-SDR，会系统性地**高估**「把强度拉满」的收益。
> 部署侧应优先按 PESQ（或主观）选强度。
> ⚠️ 注意：对 master64 而言这条不成立（它的两个指标最优点都在 dry=0），
> 故**该分歧本身也是权重相关的**，不可外推。

## 2. T5.6 · 频谱前后对比图组

### 2.1 两组图，各答一个问题

| 图 | 文件模式 | 回答 |

### 2.2 片段选取铁律：不做人工挑选

每个 (模型, 数据集) 组固定按**该模型 ΔSI-SDR 的 p10 / p50 / p90 分位数**选段，
选段规则与 clip_id 全部可从 manifest 复核。**禁止挑好看的例子。**
三个分位数正好覆盖「这条被整坏了 / 典型 / 这条救回来了」三种情形。

### 2.3 ★ 平均谱差：P19 存活判据的直接图证

`delta(f) = mean_over_clips[ 20log10|STFT(est)| ] − mean_over_clips[ 20log10|STFT(noisy)| ]`

取每格前 120 条（按 clip_id 排序），16 kHz，n_fft=1024。

> 🔴 **必须先剔除无效带**：16 kHz 采样率下 **Nyquist 恰好是 8 kHz**（rfft 仅 513 个 bin）。
> denoiser 在 16 kHz 域推理后重采样回 44.1 kHz，**8 kHz 以上是插值伪影、不是模型行为**。
> 若不剔除，顶端若干 bin 的幅度会塌到 −100 dB 以下，把统计污染成虚假的 −32 dB。
> **本表所有统计只在 0 ~ 7.8 kHz 有效带内计算。**

| 模型 | 数据集 | 0–1 kHz | 1–4 kHz | 4–7.8 kHz | 倾斜度(4k+ 减 1–4k) |
|---|---|---:|---:|---:|---:|
| denoiser master64 | valentini | −2.47 | −1.53 | **−6.15** | **−4.61** |
| denoiser master64 | synth | −4.58 | −7.19 | **−12.79** | **−5.60** |
| mel-roformer | valentini | −2.01 | −0.71 | −4.22 | −3.50 |
| mel-roformer | synth | −2.32 | −2.46 | −5.01 | −2.55 |

（原始数据 `data/denoise_spectral_delta.json`。
⚠️ 该量对重采样有微小浮点敏感性（同配置重复跑，synth 高频段在 −12.6 ~ −12.8 间抖动），
**报告只取两位有效数字**，不可当精确值引用。）

**三条读出来的结论：**

1. **不是均匀低通。** denoiser 在 valentini 上 1–4 kHz 只压 −1.53 dB，4–7.8 kHz 压 −6.15 dB ——
   压的是**随频率增长的倾斜**，而非「砍掉某个截止频率以上的一切」。
   与 P19 的结论一致（`hf_ratio` 塌陷是比例效应，不是低通）。
2. **作用量随噪声类型剧变（本图组最强证据）。** 同一个 denoiser：
   - valentini：1–4 kHz −1.53 dB，4–7.8 kHz −6.15 dB
   - synth：1–4 kHz **−7.19 dB**，4–7.8 kHz **−12.79 dB**

   即**同一条权重在瞬态噪声集上的中频抑制量是真实噪声集的 4.7 倍**（7.19 / 1.53）、
   高频段 **2.1 倍**（12.79 / 6.15）。
   这正是 P17「有效域互补」的直接机理证据：
   **denoiser 在 synth 上确实在大幅抑制，所以它在那里有效（ΔSI-SDR +11.61）；
   在 valentini 上动作温和，所以增益有限（+9.86）。**
3. **mel-roformer 的谱差全程很小**（最差一段 −5.01 dB，1–4 kHz 仅 −0.71 dB），
   与 P19 存活清单中「mel-roformer 是近恒等映射」完全吻合。
   图上它的 output 红线与 input 灰线几乎重合。

> ✅ **交叉一致性**：mel-roformer 是**原生 44.1 kHz** 推理，其谱差曲线在 8 kHz 处
> **没有断崖**（带宽更宽）；denoiser 在 8 kHz 处有断崖。两条曲线在同一张图上
> 互为对照，**反向确认了断崖来自 denoiser 内部的 16 kHz 瓶颈**，而非绘图或评测管线的问题。
