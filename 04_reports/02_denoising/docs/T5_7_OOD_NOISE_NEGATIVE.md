## 1. 核心结果：同模型在两类噪声上的表现完全反转

唯一变量是**噪声类型**。语音相同（Valentini `clean_testset_wav`）、模型相同、推理管线相同（16 kHz，P19 后）。

| 模型                          | **valentini**（真实稳态噪声）ΔSI-SDR | **synth**（freesound 瞬态噪声）ΔSI-SDR | 反转                       |
| --------------------------- | ---------------------------: | -------------------------------: | ------------------------ |
| `mel_roformer_denoise`      |                    **+6.65** |                    **+0.23**（≈0） | 🔴 真实噪声上有效 → 瞬态噪声上**失效** |
| `mel_roformer_denoise_aggr` |                    **+8.16** |                        +0.39（≈0） | 同上                       |
| `denoiser_dns48`            |                    **+9.86** |                       **+11.61** | 两类上**都强**                |
| `denoiser_dns64`            |                        +9.64 |                           +11.92 | 同上                       |
| `denoiser_master64`         |                        +9.49 |                           +11.97 | 同上                       |

**注意这不是「denoiser 反超」那么简单 —— 是 mel_roformer 在瞬态噪声上彻底失效（≈0），  
而 denoiser 保持强增益。** 反转幅度：`mel_roformer` 从 +6.65 掉到 +0.23（**−6.4 dB**），  
`denoiser` 从 +9.86 升到 +11.61（**+1.8 dB**）。

**这是本阶段最重要的发现。**

## 2. synth 集按真值 SNR 的完整分层表（P19 后）

`target_snr_db` 是**我们设定的真值**（−5 / 0 / +5 / +10 dB），因此分层无偏。  
800 条 = 200 语音 × 4 档。

### 2.1 `mel_roformer`：全档 ≈ 0（near-identity）

| 真值 SNR  |   n |   ΔSI-SDR | 说明   |
| ------- | --: | --------: | ---- |
| −5 dB   | 200 | **+0.14** | 几乎不动 |
| 0 dB    | 200 | **+0.17** | 几乎不动 |
| +5 dB   | 200 | **+0.41** | 几乎不动 |
| +10 dB  | 200 | **+0.41** | 几乎不动 |
| **ALL** | 800 | **+0.23** | —    |

`aggr` 变体同样：+0.29 / +0.31 / +0.54 / +0.49（ALL **+0.39**）。

`level_ratio` 中位 1.14（ALL），`hf_ratio` 输入 0.270 → 输出 0.255。  
**它把瞬态噪声几乎原样留在输出里。** 该数字**不受 P19 影响**，见 §3.1。

### 2.2 `denoiser`：四档全正增益，且随输入变脏单调增大

| 模型       |      −5 dB |   0 dB |  +5 dB | +10 dB |    **ALL** | `level_ratio` | `hf_ratio` in→out |   n_skipped |
| -------- | ---------: | -----: | -----: | -----: | ---------: | ------------: | ----------------- | ----------: |
| dns48    | **+14.18** | +13.02 | +11.17 |  +8.84 | **+11.61** |         0.995 | 0.270 → **0.194** | **0 / 800** |
| dns64    | **+14.86** | +12.80 | +11.43 |  +9.10 | **+11.92** |         1.005 | 0.270 → **0.196** |     0 / 800 |
| master64 | **+14.94** | +12.99 | +11.30 |  +9.15 | **+11.97** |         0.997 | 0.270 → **0.197** |     0 / 800 |

三指标全部同向为正（ALL：ΔSI-SDR +11.6~~12.0 / ΔPESQ +0.64~~0.94 / ΔSTOI +0.062~0.079）。

**注意**：`level_ratio` 中位 ≈ **1.00**（v1 是 1.04~2.03 的混乱值）—— 干净数据上  
denoiser **不做尺度补偿，只做抑制**。这也说明 v1 的 `level_ratio` 列同样被污染。

⚠️ 但 **`hf_ratio` 从 0.270 降到 0.194（−28%）** —— 这是**真实的抑制投影**，不是 P19 假象：  
瞬态噪声（门声/喷麦）的能量集中在高频，denoiser 把它们抑制掉，高频占比自然下降。  
这与 valentini 上的 −1.9% 形成鲜明对比 —— **同一动作在两类噪声上作用量差 15 倍**。  
**这正是「有效域互补」的机理证据。**

> `T5_7_PASSTHROUGH_PROBE_CORRECTION.md`）证明 denoiser **不是低通器**——  
> 它对真实 clean 的配对高频位移仅 −0.0079。`hf_ratio` 的下降是  
> **「抑制了高频占比更高的噪声」这一动作的投影**，不是对高频做滤波。

## 3. 判定：不是管道 bug

### 3.1 为什么 `mel_roformer` 的数字不受 P19 影响

P19 的机理是「wrapper 把已重采样的信号再降一次」。mel_roformer 的 wrapper  
契约率也是 44.1 kHz，**v1 的 16 kHz 路径同样走错了**。但：

> **一个近恒等映射，经过两次重采样后仍然是近恒等映射。**

它原本就几乎不改动信号（`level_ratio` ≈ 1.14），重采样错误无法让它「从有效变成无效」——  
它本来就是不变的。因此 **mel_roformer 的 ΔSI-SDR ≈ 0 是真实结论**，  
**而且 P19 修复后的重跑（+0.23）与 v1（+0.017）几乎一致**，交叉验证了这一点。

### 3.2 已排除的管道嫌疑

| 嫌疑             | 检查                                                        | 结论         |
| -------------- | --------------------------------------------------------- | ---------- |
| 合成公式错          | 复算实际 SNR = **−5.00 dB**（与设定一致）；`si_sdr_in` 中位 ≈ −5 dB     | ✅ 合成正确     |
| 片段太干净          | 逐帧噪声占比：**噪声主导帧占比 0.91**，帧噪声占比 p50 = 0.966                 | ✅ 很脏       |
| 噪声太稀疏          | `door` 主导帧 0.520，`breath_spit` 0.729，`copy-machine` 0.623 | ✅ 稀疏性假设被推翻 |
| 参考错配 / 长度错     | `reference_mode=fullref`；`est_len/in_len ≈ 0.99`，已截齐      | ✅ 正常       |
| **采样率契约（P19）** | 已修复并全量重跑；本次数字为修复后结果                                       | ✅ 已排除      |

→ **排除全部管道嫌疑。这是模型行为。**

## 4. 机理：两类噪声的时频分布差异

| 数据集       | 噪声类型                                                  | 能量分布             | 与语音的重合度                | denoiser 的 `hf_ratio` 位移 |
| --------- | ----------------------------------------------------- | ---------------- | ---------------------- | ------------------------ |
| valentini | DNS 真实噪声（稳态环境 / babble）                               | 宽带、持续、含低频        | 与语音**部分重叠**，模型学到如何分离   | **−1.9%**                |
| synth     | `door`(538) / `breath_spit`(210) / `copy-machine`(52) | **瞬态冲击，能量集中在高频** | 与语音辅音**高度相似** → 被误判为语音 | **−28%**                 |

`hf_ratio` 数据支持这个解释：

- valentini 的 `hf_ratio_in` ≈ **0.21**（与语音的 0.21 接近）→ denoiser 几乎不动频谱
- synth 的 `hf_ratio_in` ≈ **0.27**（**明显高于语音**，噪声把频谱推向上半带）→ denoiser 大幅抑制

**推论**：

1. `mel_roformer` 的抑制判据依赖"输入与语音频谱的差异" ——  
   瞬态噪声在该判据下**不像噪声**（因为它的时频结构与语音辅音相似），故**完全不处理**  
   （ΔSI-SDR +0.23，`level_ratio` 1.14，谱形几乎不变）。
2. `denoiser` 抑制的正是**高频占比高的噪声**（探针 B 证实它对纯噪声抑制 32~41 dB），  
   而瞬态噪声的能量恰好集中在高频 —— 于是**歪打正着**，抑制量比在真实噪声上还大。  
   （原写作「用固定高频抑制」，已按 T5.7 探针更正。）

> ⚠️ **本条机理仍是推断**，缺一个「只在高频加噪」的对照实验。  
> 但 `hf_ratio` 位移的 15 倍差异（−1.9% vs −28%）是**直接观测**，足以支撑「有效域互补」的结论。

## 5. 对报告的约束（必须遵守）

### 5.1 「降噪有效」必须带条件

| ❌ 不可写                       | ✅ 应写                                                                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 「Mel-RoFormer 降噪有效，+6.7 dB」 | 「在 **DNS 真实噪声**上 +6.7 dB，在 **freesound 瞬态噪声**上 **+0.23 dB（失效）**」                                                              |
| 「denoiser 质量差」              | 「denoiser 在两类噪声上**都**强（真实 +9.9、瞬态 +11.6 dB），但代价是 `hf_ratio` 大幅下降（瞬态场景 −28%）；它的缺陷是轻度系统性电平压缩（valentini `level_ratio` 中位 0.947）」 |
| 「降噪器能提升 SI-SDR」             | 「**两个模型族的有效域互补，不存在通用降噪器**」                                                                                                    |

### 5.2 `level_ratio` 是必备诊断量（第二次被证明关键）

`mel_roformer` 在 synth 上 `level_ratio` 中位 **1.14**，而 ΔSI-SDR ≈ 0。  
**SI-SDR 的尺度不变性会把"整体缩放"完全吸收** —— 只靠 SI-SDR 会得出"模型没做任何事"，  
而真相要靠 `level_ratio` 才能定性。

→ **报告必须同时给 `level_ratio`**，否则无法区分"恒等映射"与"尺度补偿"。

### 5.3 对阶段 6（级联）的约束

阶段 6 要把降噪接到分离之后。**级联前必须先判定目标场景的噪声类型**：

| 目标噪声                   | 推荐工具                                               | 依据                                      |
| ---------------------- | -------------------------------------------------- | --------------------------------------- |
| 稳态 / 环境 / babble（真实录音） | `mel_roformer`（或 denoiser，更强）                      | valentini mel +6.65 / denoiser +9.86    |
| 瞬态冲击（门声、喷麦、键盘）         | **`denoiser`（唯一可用）**                               | synth denoiser +11.6；**mel ≈ +0.23 无效** |
| 不确定                    | **两个都跑，按 `level_ratio` + `hf_ratio` 判定哪个在自己的有效域内** | —                                       |

**不得预设"降噪一定有用"**（同 P7 约束）。

## 6. 板 2 阶段 5 的完整结论（P19 后定稿）

1. **`denoiser`**：**强降噪器**，在两类噪声上都有效（valentini +9.86 / synth +11.61 dB），  
   且增益随输入变脏单调增大（synth 从 +8.84 到 +14.18）。  
   它的真实缺陷只有一条：**轻度系统性电平压缩**（valentini `level_ratio` 中位 **0.947**，  
   约 −0.5 dB），不是「整段静音」。
2. **`mel_roformer`**：**中强度增强器**，且**有效域窄**。真实噪声上 +6.65 dB，  
   瞬态噪声上 **+0.23 dB（失效）**。它的问题根源是**近恒等映射**倾向  
   （`level_ratio` 恒 0.96~1.14、对纯噪声仅降 0.04 dB）。
3. **两者有效域互补**（本条）：**瞬态噪声场景只有 denoiser 可用**；  
   真实噪声场景两者都可，denoiser 更强的代价是更大的频谱改动。

→ **合起来是一个完整、自洽、可发表的结论：「降噪器的有效性是条件性的，且不同模型的条件不同」。**

## 8. 答辩一句话

> 我们发现降噪器的有效性**取决于噪声类型，且不同模型的有效域互补**：  
> Mel-RoFormer 在 DNS 真实噪声上有 +6.7 dB 增益，但在瞬态冲击噪声（门声/喷麦）  
> 上**完全失效**（ΔSI-SDR +0.23，`level_ratio` 1.14 —— 它把噪声原样留在输出里）；  
> 而 denoiser 在两类噪声上都强（真实 +9.9 / 瞬态 +11.6 dB），代价是瞬态场景下  
> `hf_ratio` 下降 28%（对高频段的重度抑制）。  
> **所以「降噪有没有用」不是一个能用单一数字回答的问题 —— 它取决于噪声类型。**
