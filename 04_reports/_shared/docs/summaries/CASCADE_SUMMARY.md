## 3. 恒等式逐格校验：`L1 = L1b(带宽代价) + (L1 − L1b)(降噪净动作)`

| 项 | 值 |
|:---|:---|
| 校验格数 | 16 |
| 最大绝对残差 (dB) | 0.000000 |
| 判定 | PASS（残差仅来自 CSV 三位小数舍入） |

> 恒等式成立 ⇒ **没有 `L1b` 对照臂，就无法排除「涨跌其实来自带宽被砍而非降噪动作」**。

## 8. 门禁与诚实性检查

| 项 | 值 |
|:---|:---|
| 数据门禁 | **90/90 PASS** |
| 锚点 | **40/40 PASS** |
| 分离格 | **640/640 PASS**（另有 40 锚点格 PASS） |
| 诚实性（R12 / P7） | 结果变差**照报**（计划书 R12 / P7）：Δ 为负即负，不得挑数据 |
| Δ 参考系 | Δ = 该链路 − L0（同为带噪输入，不降噪） |

> ⚠️ 门禁修正记录：原判据把「denoiser 压掉 drums」（`level_ratio ≈ 0.006`）误判为信号损坏 —— **那正是被测现象本身**。正确判据 = 输入没写坏 且 输出非全零、无异常数值。详见 `tools/_cascade_regate.py`。

## 9. 复现

```bash
python tools/_cascade_experiment.py plan          # 生成 640 格计划
python tools/_cascade_experiment.py make-noisy    # 造带噪测试集

       --variants V0,V1den,V1bl,V1mel --resume    # 640 格分离推理（可断点续跑）
python tools/_cascade_experiment.py prep-post --op vbl
python tools/_cascade_experiment.py prep-post --op vden
python tools/_cascade_experiment.py post          # 后置段重算
python tools/_cascade_experiment.py summary       # 出 cascade_eval.csv/.json
python tools/_build_summaries.py --only cascade   # 重建本表
```
