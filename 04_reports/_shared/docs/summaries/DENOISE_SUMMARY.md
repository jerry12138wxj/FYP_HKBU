## 1. 口径三要素（**双口径必须分开报**）

| 项 | 取值 / 说明 |
|:---|:---|
| 口径 A（44.1 kHz） | **契约率** = 实际工作采样率。`denoiser` 内部把 44.1k→16k→44.1k 往返，故 44.1k 口径含重采样代价；**PESQ/STOI 不适用**（其定义域为 8/16 kHz） |
| 口径 B（16 kHz） | 模型原生率。`denoiser_*` 原生 16 kHz；`mel_roformer_*` 原生 44.1 kHz，此口径为**降采样后**评比 |
| 数据集 | `valentini`（真实含噪，有 clean 参考）｜`synth`（干净语音 + 合成噪声，有参考）｜`dns_dev`（**无参考** `noref`，仅统计电平塌陷） |
| SNR 分箱 | 按**输入 SI-SDR** 分：`<5dB` / `5-15dB` / `>=15dB`，另有 `ALL` 汇总 |
| 指标 | SI-SDR（dB）｜PESQ（窄带/宽带由采样率决定）｜STOI｜LSD（log-spectral distance）｜`hf_ratio`（>4 kHz 能量占比） |
| n | `n_ok` = 计入统计的条数；`n_skipped` 见 CSV 的 `skip_reason` |
